# Смета за 5 минут

Веб-приложение, в котором человек быстро собирает смету или коммерческое предложение и сохраняет его в PDF.

Им пользуются:

- предприниматели — чтобы отправить клиенту коммерческое предложение;
- офисные сотрудники — чтобы подготовить смету закупки или список расходов для руководителя.

## Файлы

| Файл | За что отвечает |
| --- | --- |
| `index.html` | Разметка страницы: поля, строки сметы, кнопки и текст, который видит человек. |
| `styles.css` | Внешний вид: размеры, отступы, читаемость на компьютере и на телефоне. |
| `script.js` | Поведение: расчёт сумм, проверка чисел, показ итога и сохранение в PDF. |

## Как открыть

Дважды щёлкните по `index.html`. Страница откроется в браузере. Установка и интернет не нужны.

## Как проверить

Добавьте две строки:

- количество `2`, цена `15 000`;
- количество `1`, цена `8 000`.

Итог должен быть **38 000 ₸** (`2 × 15 000 + 1 × 8 000`).
