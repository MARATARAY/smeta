# Правила работы в «Смета за 5 минут»

Работай только в этой папке. Перед правкой прочитай текущие файлы и опирайся на то, что уже есть.

Делай только ту функцию, которую просит пользователь. Уже работающее не ломай и не переписывай «заодно».

Только обычные HTML, CSS и JavaScript. Без npm, фреймворков, сборщиков и внешних ресурсов: ни CDN, ни шрифтов, ни картинок, ни скриптов с чужих сайтов.

Данные пользователя остаются в браузере. Ничего не отправляй в интернет: ни формы, ни запросы, ни аналитику.

Удобство:

- у полей и кнопок понятные подписи;
- поля и кнопки не ниже 44px;
- сценарий проходит с клавиатуры и на телефоне.

Деньги показывай с пробелами между тысячами: `15 000 ₸`. Пустые и неверные числа считай нулём. Никогда не показывай `NaN`.

Не запускай git и ничего не публикуй, пока пользователь сам об этом не попросит.

После работы перечисли изменённые файлы и как проверить результат.
